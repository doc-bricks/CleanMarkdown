- INV-LOCAL-02: Non-Elevation / Unprivileged User Mode (RunAsInvoker, zero UAC required)
- INV-LOCAL-03: Permissive Runtime Isolation (Core runtime MIT / BSD-3-Clause, PySide6 LGPL-3.0 dynamic linking)

- INV-LOCAL-07: Cross-Platform Parity (Linux, Windows, macOS compatibility)
