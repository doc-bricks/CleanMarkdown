Short Description:
Local Markdown viewer and editor with reading mode, PDF export and a calm interface.

Description:
CleanMarkdown is a fast local Markdown viewer and editor for people who want clear text work instead of heavy editor suites. It opens Markdown files directly from the file system, shows a calm reading view, and provides a focused raw editor without WYSIWYG overhead.

- Calm reading mode for Markdown files with clear typography and preview
- Raw Markdown editor with helper buttons for headings, lists, tables, links, images and footnotes
- Direct PDF export from the same local view
- Light and dark theme for comfortable writing day and night
- German and English interface with dynamic multilingual support (DE, EN, ES, ZH, JA, RU)
- Autosave with configurable save intervals
- Optional scroll synchronization between reading mode and raw editor
- Lightweight math formula preview ($...$, $$...$$, \(...\), \[...\])
- Relative images and local assets resolve cleanly from the document folder
- Platform-independent exchange via session interchange format (cleanmarkdown-session-v1)
- 100% local data storage without cloud requirements, accounts or telemetry

Target Audience:
For writers, developers, researchers, students and knowledge workers maintaining structured notes, documentation and prose privately on their local device. Licensed under the MIT license.
