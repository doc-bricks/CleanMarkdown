Descripción corta:
Visor y editor local de Markdown con modo lectura, exportación a PDF e interfaz limpia.

Descripción:
CleanMarkdown es un visor y editor local de Markdown rápido y eficiente para quienes buscan concentración en la redacción de textos sin la sobrecarga de suites complejas. Abre archivos Markdown directamente desde el sistema de archivos, ofrece una vista de lectura tranquila y un editor de código fuente optimizado.

- Modo de lectura sereno para archivos Markdown con vista previa limpia y tipografía cuidada
- Editor Markdown con botones de estructura para títulos, listas, tablas, enlaces, imágenes y notas al pie
- Exportación directa a PDF desde la misma vista local
- Tema claro y oscuro para trabajar cómodamente tanto de día como de noche
- Interfaz multilingüe dinámica (DE, EN, ES, ZH, JA, RU)
- Guardado automático con intervalo configurable
- Sincronización de desplazamiento opcional entre la lectura y el editor
- Vista previa ligera de fórmulas matemáticas ($...$, $$...$$, \(...\), \[...\])
- Carga de imágenes relativas y recursos locales desde el directorio del documento
- Intercambio multiplataforma mediante formato de sesión (cleanmarkdown-session-v1)
- Almacenamiento 100% local, sin necesidad de cuentas, sin nube y sin telemetría

Público objetivo:
Autores, desarrolladores, investigadores, estudiantes y profesionales que redactan notas estructuradas, documentación y textos con total privacidad. Licencia MIT.
