简短描述:
本地Markdown阅读器与编辑器，支持阅读模式、PDF导出与纯净界面。

详细描述:
CleanMarkdown 是一款快速高效的本地 Markdown 阅读器与编辑器，专为追求纯粹文本创作与阅读体验的用户设计。应用程序直接从本地文件系统打开 Markdown 文件，提供宁静的阅读模式与高效的源码编辑器，彻底告别臃肿的所见即所得负担。

- 宁静舒适的 Markdown 阅读模式，具备优美排版与即时预览
- 源码编辑器提供标题、列表、表格、链接、图片和脚注等结构化工具
- 直接从本地视图一键导出高质量 PDF 文档
- 提供浅色与深色主题，适应全天候专注工作
- 动态多语言界面支持（德语、英语、西班牙语、简体中文、日语、俄语）
- 自动保存功能，保存时间间隔完全可调
- 阅读视图与源码编辑视图之间可选的滚动同步
- 轻量级数学公式渲染支持 ($...$, $$...$$, \(...\), \[...\])
- 自动解析并加载文档相对路径下的本地图片与资源
- 基于通用会话格式（cleanmarkdown-session-v1）的跨平台数据互通
- 100% 本地数据存储，无云端绑定，无需注册账户，无遥测追踪

目标受众:
适用于追求纯粹本地隐私与高效文本管理的作家、开发者、科研人员、学生与知识工作者。基于 MIT 开源许可证发布。

关键词:
markdown, 编辑器, 阅读器, 预览, pdf导出, 笔记, 写作
