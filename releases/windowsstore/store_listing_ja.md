簡単な説明:
読書モード、PDF書き出し、シンプルなUIを備えたローカルMarkdownビューア＆エディタ。

詳細説明:
CleanMarkdown は、過剰な機能を持つ巨大なエディタスイートではなく、純粋で快適なテキスト作業を求める人々のための高速なローカル Markdown ビューア＆エディタです。ファイルシステムから Markdown ファイルを直接開き、落ち着いた読書表示とWYSIWYGの無駄を省いた集中できるソースエディタを提供します。

- 快適なタイポグラフィとクリーンなプレビューを備えた読書モード
- 見出し、リスト、テーブル、リンク、画像、脚注を素早く入力できる構造化ボタン付きエディタ
- 同じローカル表示から直接 PDF へワンクリック書き出し
- 昼夜問わず目に優しいライト＆ダークテーマ
- 6言語（DE, EN, ES, ZH, JA, RU）に対応した動的な多言語ユーザーインターフェース
- 間隔を自由に設定できる自動保存（オートセーブ）機能
- 読書モードとエディタ間のオプションのスクロール同期
- 軽量な数式プレビュー（$...$, $$...$$, \(...\), \[...\]）に対応
- 開いているドキュメントの相対画像およびローカルアセットを正確に読み込み
- セッション形式（cleanmarkdown-session-v1）によるプラットフォーム間連携
- アカウント登録不要、クラウド同期不要、テレメトリ無しの100%完全ローカルデータ保持

対象読者:
プライバシーを尊重し、構造化されたノート、ドキュメント、執筆原稿を安全にローカルで管理したい作家、開発者、研究者、学生、ナレッジワーカー向け。MITライセンス。
