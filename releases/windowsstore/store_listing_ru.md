Краткое описание:
Локальный просмотрщик и редактор Markdown с режимом чтения, экспортом в PDF и чистым интерфейсом.

Полное описание:
CleanMarkdown — это быстрый и удобный локальный просмотрщик и редактор файлов Markdown для тех, кому важна концентрация на тексте без перегруженных офисных комплексов. Приложение открывает файлы Markdown напрямую с диска, предлагает спокойный режим чтения и сфокусированный редактор исходного кода.

- Спокойный режим чтения с качественной типографикой и аккуратным предпросмотром
- Редактор исходного кода со структурированными кнопками для заголовков, списков, таблиц, ссылок, изображений и сносок
- Прямой экспорт в PDF из того же локального представления
- Светлая и темная темы для комфортной работы днем и ночью
- Динамический многоязычный интерфейс (DE, EN, ES, ZH, JA, RU)
- Автосохранение с настраиваемым временным интервалом
- Опциональная синхронизация прокрутки между режимом чтения и редактором
- Легковесный предпросмотр математических формул ($...$, $$...$$, \(...\), \[...\])
- Корректная загрузка относительных изображений и локальных ресурсов из каталога документа
- Кроссплатформенный обмен через формат сессий (cleanmarkdown-session-v1)
- 100% локальное хранение данных без привязки к облаку, учетных записей и телеметрии

Целевая аудитория:
Писатели, разработчики, исследователи, студенты и специалисты, работающие со структурированными заметками и текстами с соблюдением полной конфиденциальности. Лицензия MIT.
